# /status

Exibe o painel de contexto do projeto atual.

## O que fazer

1. Execute os comandos bash de coleta definidos em `skills/ai/project-status.md`
2. Leia modelo e uso de contexto do ambiente Claude Code
3. Renderize o painel visual no terminal conforme o formato definido na skill
4. Se contexto > 75%, exiba o aviso de alerta abaixo do painel

Não adicione texto antes nem depois do painel, a menos que o contexto
esteja acima de 75% (nesse caso, apenas o aviso padrão da skill).
