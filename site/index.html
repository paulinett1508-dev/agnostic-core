O que é

O agnostic-core é um conjunto de instruções em Markdown. Cada arquivo descreve um padrão de trabalho: como revisar código, como organizar um commit, como fazer uma migração de banco sem quebrar o que já foi aplicado, como auditar uma tela.

Quando você instala o acervo num projeto, o Claude Code passa a conhecer esses padrões e a usá-los nas partes do projeto que combinam com eles.

Não é um framework, não tem runtime e não altera o seu código sozinho. Nada roda por conta própria: ele fornece referências, e você decide quais aceitar.

Para quem é:

  • Quem usa o Claude Code e quer os mesmos padrões em vários projetos.
  • Equipes que querem um vocabulário comum para revisão, commits e deploy.
  • Quem prefere ler a regra e discordar por escrito, em vez de seguir um default escondido.

Opinião escrita

As skills defendem posições, e cada uma diz o motivo. Três exemplos:

Nada de cara de IA
Proíbe defaults visuais típicos de interfaces geradas por IA, com a lista e o porquê.
skills/design/sem-cara-de-ia.md
Modo caveman
Corta a resposta da IA em cerca de 75%, mantendo a precisão técnica.
skills/behavioral/caveman.md
Precedência entre skills
Diz qual skill perde para qual quando duas tratam do mesmo processo.
docs/precedencia-de-skills.md

Discordar é esperado e barato: não instale a skill, ou instale e edite.

Como funciona

  1. 1

    Instala

    Rode o instalador na raiz do repositório. Ele adiciona .agnostic-core/ como submódulo.

  2. 2

    Detecta a stack

    Reconhece React, Vue, Next, Express, FastAPI, Django, Docker, Prisma e outras. Escreve .agnostic-skills com a seleção e nunca sobrescreve uma seleção existente.

  3. 3

    Usa a seleção

    No Claude Code, o CLAUDE.md passa a apontar para as skills da sua stack, e a camada .claude/skills/ liga a autodescoberta. Em outras ferramentas, como Cursor ou Copilot, o acervo é Markdown: você referencia os arquivos que quer usar.

Sem .agnostic-skills, o acervo inteiro é espelhado no system prompt de toda sessão. Por isso a seleção importa.

Instalação

Execute na raiz de qualquer repositório git.

Bash · Linux, macOS, WSL
curl -sL https://raw.githubusercontent.com/paulinett1508-dev/agnostic-core/master/scripts/install.sh | bash
PowerShell · Windows
iwr -useb https://raw.githubusercontent.com/paulinett1508-dev/agnostic-core/master/scripts/install.ps1 | iex
npm · qualquer plataforma com bash
npx agnostic-core@latest init
Git submódulo manual
git submodule add https://github.com/paulinett1508-dev/agnostic-core.git .agnostic-core
git submodule update --init
